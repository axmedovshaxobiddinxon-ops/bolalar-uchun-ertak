# LOYIHA MAQSADI

Ushbu loyiha bolalar uchun tarbiyaviy ertaklar yaratishga mo‘ljallangan.

Asosiy yo‘nalishlar:

* Ezgulik
* Halollik
* Odob-axloq
* Ilm-ma'rifat
* Kitobxonlik
* Vatanparvarlik
* Ota-onaga hurmat
* Ustozga ehtirom
* Do‘stlik
* Mehnatsevarlik

Barcha ertaklar bolalar psixologiyasiga mos, ijobiy va tarbiyaviy ruhda yozilishi shart.
